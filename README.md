# Kibriya Aslam — Developer Portfolio

A responsive dark-premium developer portfolio built with React, Vite, CSS, and Lucide icons.

## Run locally

1. Install Node.js (LTS recommended).
2. Extract this folder and open it in VS Code.
3. Open a terminal in this project folder and run:

   ```bash
   npm install
   npm run dev
   ```

4. Open the local URL Vite prints in the terminal.

## Before publishing

Update these placeholders in `src/App.jsx`:
- `YOUR_EMAIL@example.com` — your real professional email.
- `https://www.linkedin.com/` — your actual LinkedIn profile URL.

Project links for Grand Cart, FitWise, MediVera, Surveillance AI, and HomeAssist currently point to your GitHub profile because exact repository URLs have not been supplied. Replace each with its individual repository or live-demo URL when ready.

The Movify live link and GitHub profile are included from the information provided.

## Build for deployment

```bash
npm run build
```

The production-ready files will be created in the `dist` folder. You can deploy the project to Vercel, Netlify, or GitHub Pages.
